# ACTIVE PLOT

> เส้นทางระยะยาวและข้อห้ามออกนอกแกนอยู่ใน `STORY_ROADMAP.md`

## Plot หลักที่กำลังดำเนิน
1. การเมืองภายในราชสำนักต้าลี่ และการตรวจหาคนในที่เปิดทางให้ฝังแผ่นโลหะใต้ฐานพิธี
2. สืบสวนเหตุลอบสังหาร ตราเคลื่อนย้าย ผู้ควบคุมงูยักษ์ และองค์กรจันทราดับ
3. ตรวจสอบแผ่นโลหะจันทร์เสี้ยวสีดำซึ่งถูกฝังไว้อย่างน้อยหลายเดือน
4. ตรวจสอบชายปริศนาในคราบเจ้าหน้าที่หอสมุดและร่างอักขระที่ไม่เข้าข่ายมนุษย์ ภูติ ปีศาจ หุ่นอาคม หรือร่างจำแลง
5. แยกข้อเท็จจริงออกจากเรื่องเล่าที่ศัตรูสร้างเพื่อให้จิ่งอันสงสัยชาติกำเนิดและความทรงจำ
6. ความสัมพันธ์ระหว่างพี่น้อง (จิ่งอัน ↔ จิ่งเจิ้น ↔ จิ่งเหยา) ที่แน่นแฟ้นผิดจากธรรมเนียมชิงอำนาจในราชวงศ์
7. ตรวจสอบ “ประตูที่ไม่ควรเปิดจากฝั่งนี้” ใต้ฐานหินอัคคี โดยยังไม่เปิดประตูหรือเฉลยความจริงก่อนเวลา

## Plot ที่ต้องดำเนินต่อทันที
- อายัดและตรวจหนังสือเก่าที่ชายปริศนาทิ้งไว้ โดยถือภาพทารกกับเชือกสิบแปดสายเป็นสิ่งชักนำจนกว่าจะพิสูจน์ได้
- ตรวจอักขระสีดำ เศษป้ายเจ้าหน้าที่ และรอยแผลวงกลมที่ชายปริศนาแสดง
- ตรวจสอบตัวจริงของเจ้าหน้าที่หอสมุดและช่องโหว่ที่ทำให้ร่างปริศนาเข้าสู่วัง
- ค้นบันทึกต้องห้ามเกี่ยวกับ “จันทราดับ” และเหตุการณ์เมื่อ 17 ปีก่อน
- ตรวจเสียงเคาะสามครั้งจากใต้ฐานพิธีและความเชื่อมโยงกับประตู โดยยังไม่เปิดประตู
- รักษางูยักษ์และตรวจตราควบคุมที่ผูกกับแก่นวิญญาณ
- ตรวจซากหินอัคคี ตราเคลื่อนย้าย และรายชื่อผู้มีสิทธิ์เข้าพื้นที่ย้อนหลังหลายเดือน
- ส่งข้อมูลผู้ทำสัญญารายใหม่ขึ้นทะเบียนกับกรมภูติหลวง
- ตรวจความผิดปกติที่จิ่งอันได้ยินเสียงทางจิตของเสี่ยวเถาก่อนเซวียนเอ๋อร์

## ข้อเท็จจริงที่ยังไม่ยืนยัน
- คำอ้างว่าชายปริศนาเคยเป็นคนของจันทราดับและทรยศเมื่อ 17 ปีก่อน
- คำอ้างว่าเขาเป็นผู้พาจิ่งอันออกมาจากประตู
- ภาพทารกที่มีเชือกสิบแปดสายเป็นภาพเพิ่งสร้างขึ้น มิใช่หลักฐานประวัติศาสตร์
- ตัวตน ผู้สร้าง และวิธีควบคุมร่างอักขระยังไม่ทราบ
- คำเตือน “อย่าเชื่อแม้แต่ความทรงจำของตนเอง” อาจเป็นทั้งเบาะแสหรือการชักนำ

## Plot ระยะยาว
- ภาค 1: พิธีอัญเชิญโลหิต
- ภาค 2: คดีภูติไร้นาย
- ภาค 3: เงาในราชสำนัก
- ภาค 4: เพลิงชายแดน
- ภาค 5: สงครามห้าแคว้น
- ภาค 6: ประตูเก้าหาง
- ทุกภาคต้องเชื่อมกับองค์กรจันทราดับและคำถาม “คนหรือภูติกันแน่ที่เป็นปีศาจ?”
