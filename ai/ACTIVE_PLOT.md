# ACTIVE PLOT

> เส้นทางระยะยาวและข้อห้ามออกนอกแกนอยู่ใน `STORY_ROADMAP.md`

## Plot หลักที่กำลังดำเนิน
1. การเมืองภายในราชสำนักต้าลี่
2. องค์ชายรองถูกบังคับให้เข้าร่วมพิธีอัญเชิญ ทั้งที่ตัวเองอยากอยู่อย่างสบาย
3. กลุ่มผู้ใช้ภูติฝ่ายมืดวางแผนหมายสังหารในวันพิธี
4. ความสัมพันธ์ระหว่างพี่น้อง (จิ่งอัน ↔ จิ่งเจิ้น ↔ จิ่งเหยา) ที่แน่นแฟ้นผิดจากธรรมเนียมชิงอำนาจในราชวงศ์

## Plot ที่จะเกิดขึ้นเร็ว ๆ นี้
- วันพิธีอัญเชิญ
- หินอัคคีไม่ตอบรับ
- การลอบสังหาร
- การปรากฏตัวของว่างเหยียน + อู่อี (พลังสีม่วง)
- เซวียนเอ๋อร์ทำสัญญากับเสี่ยวเถาในช่วงเหตุการณ์เดียวกัน
- หลังพิธี ข้อมูลของจิ่งอันและภูติทั้งสองต้องถูกส่งขึ้นทะเบียนกับกรมภูติหลวง
- ทะเบียนและบันทึกในหอจดหมายเหตุภูติจะกลายเป็นเบาะแสของคดีภูติในช่วงถัดไป

## Plot ระยะยาว
- ภาค 1: พิธีอัญเชิญโลหิต
- ภาค 2: คดีภูติไร้นาย
- ภาค 3: เงาในราชสำนัก
- ภาค 4: เพลิงชายแดน
- ภาค 5: สงครามห้าแคว้น
- ภาค 6: ประตูเก้าหาง
- ทุกภาคต้องเชื่อมกับองค์กรจันทราดับและคำถาม “คนหรือภูติกันแน่ที่เป็นปีศาจ?”
