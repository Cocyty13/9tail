# ACTIVE PLOT

## Plot หลักที่กำลังดำเนิน
1. การเมืองภายในราชสำนักต้าลี่ระหว่างฝ่ายรัชทายาทกับฝ่ายฮองเฮา
2. องค์ชายรองถูกบังคับให้เข้าร่วมพิธีอัญเชิญทั้งที่ทุกคนคาดว่าเขาไม่มีพลัง
3. กลุ่มผู้ใช้ภูติฝ่ายมืดวางแผนหมายสังหารในวันพิธี

## Plot ที่จะเกิดขึ้นเร็ว ๆ นี้
- วันพิธีอัญเชิญ
- หินอัคคีไม่ตอบรับ
- การลอบสังหาร
- การปรากฏตัวของจิ้งจอกเก้าหางสองตน (พลังสีม่วง)

## Plot ระยะยาว
- ความสัมพันธ์กับนางเอกจากหนานเจียง
- สงครามระหว่างอาณาจักร
- ความลับของจิ้งจอกเก้าหาง
