# ACTIVE PLOT

## Plot หลักที่กำลังดำเนิน
1. การเมืองภายในราชสำนักต้าลี่
2. องค์ชายรองถูกบังคับให้เข้าร่วมพิธีอัญเชิญ
3. กลุ่มผู้ใช้ภูติฝ่ายมืดวางแผนหมายสังหารในวันพิธี
4. ความสัมพันธ์ระหว่างพี่น้อง (เซวียน ↔ เจิ้น) ที่ดีผิดปกติ

## Plot ที่จะเกิดขึ้นเร็ว ๆ นี้
- วันพิธีอัญเชิญ
- หินอัคคีไม่ตอบรับ
- การลอบสังหาร
- การปรากฏตัวของฮานะ + ยูคิ (พลังสีม่วง)

## Plot ระยะยาว
- ความสัมพันธ์กับซากุระ (นางเอกจากหนานเจียง)
- ปมของลุงทั้งสอง (หลี่เฉิน / หลี่หยาง)
- สงครามระหว่างอาณาจักร
- ความลับของจิ้งจอกเก้าหาง
