# ACTIVE PLOT

> เส้นทางระยะยาวและข้อห้ามออกนอกแกนอยู่ใน `STORY_ROADMAP.md`

## Plot หลักที่กำลังดำเนิน
1. การเมืองภายในราชสำนักต้าลี่
2. สืบสวนเหตุลอบสังหารในพิธีอัญเชิญและผู้ฝังตราเคลื่อนย้ายใต้หินอัคคี
3. ตามหาผู้สั่งการตัวจริงซึ่งหลบหนี พร้อมตรวจสัญลักษณ์จันทร์เสี้ยวสีดำ
4. ความสัมพันธ์ระหว่างพี่น้อง (จิ่งอัน ↔ จิ่งเจิ้น ↔ จิ่งเหยา) ที่แน่นแฟ้นผิดจากธรรมเนียมชิงอำนาจในราชวงศ์
5. ตรวจสอบ “ประตูที่ไม่ควรเปิดจากฝั่งนี้” ใต้ฐานหินอัคคี โดยยังไม่เปิดประตูหรือเฉลยความจริงก่อนเวลา

## Plot ที่จะเกิดขึ้นเร็ว ๆ นี้
- รักษางูยักษ์และตรวจตราควบคุมที่ผูกกับแก่นวิญญาณ
- สอบสวนมือสังหารที่ยังมีชีวิต ตรวจศพผู้ควบคุม และตามรอยผู้สั่งการบนหลังคา
- ตรวจซากหินอัคคี ฐานพิธี ตราเคลื่อนย้าย และเอกสารผู้มีสิทธิ์เข้าพื้นที่ก่อนงาน
- ข้อมูลของจิ่งอัน ว่างเหยียน อู่อี เซวียนเอ๋อร์ และเสี่ยวเถาต้องถูกส่งขึ้นทะเบียนกับกรมภูติหลวง
- ทะเบียนและบันทึกในหอจดหมายเหตุภูติจะกลายเป็นเบาะแสของคดีภูติในช่วงถัดไป
- ตรวจความผิดปกติที่จิ่งอันได้ยินเสียงทางจิตของเสี่ยวเถาก่อนเซวียนเอ๋อร์

## Plot ระยะยาว
- ภาค 1: พิธีอัญเชิญโลหิต
- ภาค 2: คดีภูติไร้นาย
- ภาค 3: เงาในราชสำนัก
- ภาค 4: เพลิงชายแดน
- ภาค 5: สงครามห้าแคว้น
- ภาค 6: ประตูเก้าหาง
- ทุกภาคต้องเชื่อมกับองค์กรจันทราดับและคำถาม “คนหรือภูติกันแน่ที่เป็นปีศาจ?”
