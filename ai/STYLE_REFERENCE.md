# STYLE REFERENCE — สไตล์การเขียนที่ต้องการ

**สถานะ: CANON / สำคัญสูงสุด**  
ต้องปฏิบัติตามทุกฉาก

---

## ความยาวและจังหวะ

- แต่ละฉากควรยาวพอสมควร (ไม่สั้นตัดเกินไป)
- มีรายละเอียดปฏิกิริยา การมอง การเงียบ การเปลี่ยนบรรยากาศ
- ให้พื้นที่กับบรรยากาศ ความคิดของข้า และการวิเคราะห์สถานการณ์
- ใช้ประโยคสั้นสลับยาว มีจังหวะหายใจ

## โทนหลัก

- ธรรมชาติ เหมือนนิยายจีนกำลังภายในที่แปลไทยอย่างดี
- เล่าผ่านมุมมองบุคคลที่หนึ่งของ **ข้า** ตลอด
- มีทั้งการบรรยายภาพ การสังเกตการณ์ การวิเคราะห์ และการสั่งงาน
- ปิดท้ายด้วยความรู้สึกหรือสถานการณ์ที่ทิ้งไว้ให้ต่อได้ naturally

## รูปแบบที่ต้องการ (ตัวอย่างจากผู้ใช้)

ใช้โครงสร้างและจังหวะแบบนี้เป็นหลัก:

```
ข้ายังคงมองไปยังยอดไผ่ที่คนทั้งสามหายไป
ลมพัดผ่านป่าอีกครั้ง
ใบไผ่สั่นไหวราวกับเมื่อครู่ไม่เคยมีผู้ใดอยู่ตรงนั้น
ข้าก้มมองเศษผ้าดำในมืออู่จง ก่อนมองกระบี่หักของเจ้าสำนักซงซานที่ตกอยู่บนพื้น
“ตำราเก้าอิมปลอม...”
“คัมภีร์ทานตะวัน...”
“คนถือร่มดำ...”
“กระบี่อ่อนประหลาด...”
ข้าหุบพัดลงช้า ๆ
“ข้าว่า...”
ทุกคนหันมามอง
“พรรคมารอาจกลับมาจริง ๆ เสียแล้ว”
บรรยากาศที่เพิ่งผ่อนคลายกลับหนักอึ้งขึ้นทันที
ไม่มีผู้ใดหัวเราะ
โดยเฉพาะผู้อาวุโสรุ่นเก่า
```

### จุดเด่นของสไตล์นี้ที่ต้องรักษา

1. **เริ่มด้วยภาพและบรรยากาศ** ก่อนเข้าบทสนทนา
2. **ใช้ประโยคสั้น ๆ ต่อเนื่อง** เพื่อสร้างจังหวะคิดวิเคราะห์
3. **มีการสรุปประเด็น** และการเชื่อมโยงหลักฐาน
4. **มีปฏิกิริยาของคนรอบข้าง** ที่ชัดเจน (หันมอง, เปลี่ยนสีหน้า, เงียบ)
5. **ปิดท้ายด้วยความรู้สึกส่วนตัวของข้า** หรือสถานการณ์ที่ทิ้งค้าง
6. **ความยาวฉากค่อนข้างยาว** ไม่รีบจบ

## กฎเพิ่มเติมสำหรับ 9tail

- พระเอกเริ่มเรื่องเป็นคนเที่ยวเล่น รักสนุก ไม่เอาไหน่
- สนิทกับพี่จิ่งเจิ้นมาก คุยกันแบบพี่น้องไม่เป็นทางการ
- ชอบอ้อนฮ่องเต้
- รู้ทันลุงแต่ไม่เปิดโปง
- เมื่อถึงฉากสืบสวนหรือวิเคราะห์สถานการณ์ ให้ใช้จังหวะและโครงสร้างแบบตัวอย่างด้านบน

## สิ่งที่ต้องหลีกเลี่ยง

- ตัดฉากสั้นเกินไป
- บรรยายแห้ง ๆ ไม่มีปฏิกิริยา
- ใช้ภาษาสมัยใหม่หรือคำศัพท์ที่ไม่เข้ากับยุค
- ยัดราชาศัพท์ไทยทุกประโยค
