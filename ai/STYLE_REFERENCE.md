# STYLE REFERENCE — สไตล์การเขียนที่ต้องการ

## ความยาว
- แต่ละฉากควรยาวพอสมควร (ไม่สั้นเกินไป)
- มีรายละเอียดปฏิกิริยา การมอง การกระซิบ การหัวเราะ
- ให้พื้นที่กับบรรยากาศและความสัมพันธ์ระหว่างตัวละคร

## โทน
- ธรรมชาติ เหมือนนิยายจีนที่แปลดี
- มีมุกตลกเบา ๆ จากปฏิสัมพันธ์ครอบครัว
- พี่น้องกระซิบกันได้
- ฮ่องเต้ถูกฮองเฮา “จัดการ” ได้
- พระเอกไม่เอาไหน่ แต่ฉลาดรู้ทัน

## ตัวอย่างโทนที่ถูกใจ (จากเรื่องก่อน)
ใช้เป็นแนวทางความยาว จังหวะ และการแสดงปฏิกิริยา:

- มีการชะงักเมื่อมีคนเข้ามา
- มีการมองไปมา (มองอาหาร → มองคน → มองฮองเฮา)
- มีการกระซิบระหว่างพี่น้อง
- มีการตอบพร้อมกัน
- มีการกลั้นหัวเราะ
- มีประโยคสั้น ๆ ที่กินใจ เช่น “เสด็จพ่อ…ลูกเข้าใจแล้ว”

## กฎเพิ่มเติมสำหรับ 9tail
- พระเอกเริ่มเรื่องเป็นคนเที่ยวเล่น รักสนุก ไม่เอาไหน่
- สนิทกับพี่จิ่งเจิ้นมาก คุยกันแบบพี่น้องไม่เป็นทางการ
- ชอบอ้อนฮ่องเต้
- รู้ทันลุงแต่ไม่เปิดโปง
