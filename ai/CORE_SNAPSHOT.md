# CORE SNAPSHOT (อัปเดตล่าสุด — 2 ส.ค. 2026)

## สถานะปัจจุบัน
- **อันเฉินและเยว่หลินได้รับแต่งตั้งเป็นมือปราบฝึกหัดในสำนักมือปราบ กรมภูติหลวง**
- หลังถูกลอบโจมตีกลางคืนขณะกลับจากตลาด → ฝึกปราณ → ได้รับกำไลโลหิตอสูรอัคคี → ปลดผนึกหอก → เข้าสำนักมือปราบ
- หลี่ อันเฉิน ทำพันธสัญญาขั้นต้นกับว่างเหยียนและอู่อี จิ้งจอกเก้าหางระดับม่วงทั้งสองตน
- หลิน เยว่หลิน ทำสัญญากับเสี่ยวเถา ภูติแมวดำระดับขาว
- มู่หลันทำสัญญากับลูกเหยี่ยววายุระดับเหลือง
- อันเฉินมีปราณอัคคีดั้งเดิม (Origin Fire) และสามารถซึมซับพลังจากภูติคู่สัญญาได้
- เยว่หลินมีปราณบุปผา (อนุพันธ์สายวารี) และเรียนกระบวนท่าขลุ่ยบุปผาจากว่างเหยียนแล้ว
- อันเฉินครอบครองกำไลโลหิตอสูรอัคคี ซึ่งปลดผนึกหอกลึกลับที่มีเจตจำนงของตนเอง
- เส้นทางระยะยาวถูกล็อกไว้ใน `STORY_ROADMAP.md`: สืบสวนคดีภูติ → จันทราดับ → การเมืองราชสำนัก → ชายแดน → สงคราม → ประตูแดนภูติ

## ข้อมูลสำคัญที่ล็อกแล้ว

### ราชวงศ์ต้าลี่
- ฮ่องเต้: หลี่ เทียนเชิง (ภูติเสือขาวระดับสูง มีสามร่าง แต่ไม่มีผู้เคยเห็นร่างจำแลง)
- ฮองเฮา: เซี่ย หมิงเยว่
- องค์ชายใหญ่: หลี่ จิ่งเจิ้น (ภูติกิเลนดำระดับสูง มีสามร่าง แต่ไม่มีผู้เคยเห็นร่างจำแลง) — สนิทกับองค์ชายรองมาก / อดีตมือปราบ
- องค์ชายรอง: **หลี่ อันเฉิน** (พระเอก) — เรียก **อันเฉิน**
- องค์หญิง: **หลี่ เหยาเฟย** — เรียก **เหยาเฟย** (สดใส ซน)

### ตระกูลแม่ทัพมู่แห่งต้าลี่จิง
- แม่ทัพมู่ เหยียน อายุ 52 ปี — ผู้บัญชาการกองพิทักษ์นคร / อาจารย์สอนปราณและพื้นฐานหอกให้อันเฉิน
- มู่ เฉิง อายุ 25 ปี — บุตรชายคนโต รองผู้บัญชาการหนุ่ม สุขุม มีวินัย และเป็นสหายฝึกอาวุธของรัชทายาท
- มู่ หลัน อายุ 21 ปี — บุตรสาวคนเล็ก รุ่นเดียวกับพระเอก ฉลาดแกมซน พูดตรง
- คนของแม่ทัพมู่ตามอันเฉินมาตั้งแต่อันเฉินอายุ 14 ปี (อันเฉินรู้และยอมรับ)

### จิ้งจอกเก้าหาง (ปรากฏตัวและทำสัญญาแล้ว)
- **ว่างเหยียน** — พี่สาว สุขุม สง่างาม / ผู้สอนปราณ / พัฒนากระบวนท่าขลุ่ยบุปผา / รู้ความลับกำไลโลหิตอสูรอัคคีแต่ปิดบังชื่อเจ้าของเดิม
- **อู่อี** — น้องสาว ขี้เล่น ซุกซน / รู้จักกำไลและเจ้าของเดิม แต่ถูกว่างเหยียนห้ามเปิดเผย
- ทั้งคู่เป็นภูติระดับม่วงและมีสามร่าง: จิ้งจอกน้อย / กึ่งมนุษย์ / หญิงสาวจำแลง
- ทั้งคู่เปิดเผยว่ามีอายุราว 2,000 ปี แต่ยังไม่บอกว่าใช้ชีวิตอยู่ที่ใดตลอดช่วงเวลานั้น
- อันเฉินทำได้เพียงพันธสัญญาขั้นต้น ยังใช้พลังทั้งหมดของทั้งคู่ไม่ได้

### นางเอก
- ชื่อ: **หลิน เยว่หลิน** — เรียก **เยว่หลิน**
- องค์หญิงแห่งหนานเจียง / มือปราบฝึกหัด
- บุคลิก: ง้อ ขี้เล่น น่ารัก
- ภูติ: ภูติแมวดำระดับขาวชื่อ **เสี่ยวเถา**
- ปราณ: บุปผา (อนุพันธ์สายวารี)
- วิชา: กระบวนท่าขลุ่ยบุปผา (ท่าที่ 1 “ห้วงสะกด”)
- เสี่ยวเถา: ซุกซน จอมวางแผน มีสามร่าง และเคยเผยร่างกึ่งภูติในการต่อสู้แล้ว (หญิงสาวผมสั้นหูแมว ใช้คุไนคู่)
- อันเฉินได้ยินเสียงสื่อสารทางจิตของเสี่ยวเถาก่อนเยว่หลินอย่างผิดปกติ

### ระบบปราณ (Canon ใหม่ — สำคัญมาก)
- ผู้ใช้ภูติมีปราณกำเนิดได้เพียงหนึ่งชนิดตลอดชีวิต ไม่มีข้อยกเว้น
- ปราณดั้งเดิมมีเพียง 4 ชนิด: พสุธา / วารี / วายุ / อัคคี
- ปราณอนุพันธ์:
  - พสุธา → หิน, ทราย, โลหะ, ไม้, พืช
  - วารี → น้ำแข็ง, หมอก, บุปผา, พิษ
  - วายุ → เสียง, ความเร็ว, ความดันอากาศ
  - อัคคี → ลาวา, ควัน, ระเบิด, ความร้อน
- กฎ: หนึ่งคนมีหนึ่งปราณกำเนิด / ปราณย่อยมาจากต้นกำเนิดเพียงสายเดียว / ปราณดั้งเดิมเหนือกว่าปราณย่อย
- อันเฉิน = ปราณอัคคีดั้งเดิม (Origin Fire)
- เยว่หลิน = ปราณบุปผา (อนุพันธ์สายวารี)

### ระบบซึมซับพลังภูติ
- ภูติดึงพลังจากนายได้ แต่นายก็สามารถดึงพลังกลับจากภูติได้เช่นกัน
- ยิ่งภูติระดับสูง การซึมซับยิ่งรวดเร็ว
- อันเฉินเริ่มใช้ได้เองโดยสัญชาตญาณ (ความเร็วเพิ่ม ประสาทสัมผัสดีขึ้น ปัดอาวุธได้เอง)

### กำไลโลหิตอสูรอัคคี + หอก
- ที่มา: นักพรตอู่สือฝากไว้ตั้งแต่จักรพรรดิยังหนุ่ม กล่าวว่าวันหนึ่งกำไลจะเลือกเจ้าของเอง
- ตอบสนองต่ออันเฉินทันที สวมข้อมือเอง ถอดไม่ออก
- ว่างเหยียนกับอู่อีรู้จักและตกใจมาก เดิมเป็นของภูติระดับสูงในแดนภูติ แต่ไม่ยอมบอกชื่อเจ้าของเดิม
- ปลดผนึกอาวุธชิ้นแรก: หอกด้ามสีแดงสด ใบหอกสีดำ มีพู่แดง (พันธะสะกด)
- หอกมีเจตจำนงของตนเอง ลอยเองได้ ส่งความทรงจำบางส่วนเข้าสู่จิตของอันเฉิน
- อันเฉินยังควบคุมหอกไม่ได้เต็มที่

### กฎสัญญาที่ต้องจำ
- ภูติระดับขาวขึ้นไปสามารถมีร่างภูติ ร่างกึ่งมนุษย์ และร่างจำแลงเป็นมนุษย์สมบูรณ์
- เชือกสวรรค์ปรากฏชั่วครู่เมื่อทำสัญญา แล้วซ่อนหายเมื่อสัญญาสมบูรณ์
- เมื่อมนุษย์หรือภูติฝ่ายใดฝ่ายหนึ่งตาย เชือกจะปรากฏอีกครั้ง ก่อนขาดและสลายถาวร
- เมื่อความสัมพันธ์ถึงขีดสุด ภูติอาจบอกนามจริงแก่เจ้าของเพียงผู้เดียว เพื่อเข้าสู่ **พันธสัญญานามแท้**
- อันเฉินต้องได้รับนามจริงจากว่างเหยียนและอู่อีโดยสมัครใจทั้งคู่ จึงจะใช้ร่างจิ้งจอกสวรรค์สีทองและกระบี่จิ้งจอกสวรรค์ได้
- นามจริงของว่างเหยียนและอู่อียังเป็นความลับ

### หน่วยงานภูติที่ต้องจำ
- **กรมภูติหลวง** — ขึ้นทะเบียนผู้ใช้ภูติ รับรายงานเหตุสำคัญ และดูแลข้อมูลเกี่ยวกับภูติ
- **หอจดหมายเหตุภูติ** — เก็บทะเบียน ประวัติ รายงานคดี ตำรา และบันทึกเหตุการณ์ในอดีต
- **สำนักฝึกภูติ** — อยู่ใต้กรมภูติหลวง ใช้ฝึกผู้ทำสัญญาและรักษาภูติบาดเจ็บ
- **สำนักมือปราบ** — หน่วยงานปฏิบัติการของกรมภูติหลวง / อันเฉินและเยว่หลินเป็นมือปราบฝึกหัด / หัวหน้ากองปัจจุบันคือ กู้เหวินโจว

### บุคลิกพระเอก (สำคัญ)
- เริ่มเรื่องเป็นคน **เที่ยวเล่น รักสนุก ไม่เอาไหน่**
- ไม่จริงจังกับอำนาจหรือตำแหน่ง
- สนิทกับรัชทายาท (พี่จิ่งเจิ้น) มาก
- ชอบอ้อนฮ่องเต้เสมอ
- รู้ทันอา/ญาติที่มีเบื้องหลัง แต่ไม่แสดงออก
- ภายนอกดูสบาย ๆ ไม่ใส่ใจการเมือง
- ในเหตุพิธี อันเฉินเลือกช่วยภูติที่ถูกทรมาน
- ชอบลอบออกจากวังไปเที่ยวเมืองมาตั้งแต่เด็ก

## หลักฐานและข้อจำกัดใหม่
- แผ่นโลหะจันทร์เสี้ยวสีดำใต้ฐานพิธีเป็นหลักฐานว่าฝ่ายศัตรูเตรียมการล่วงหน้าและอาจมีผู้ช่วยจากภายในวัง
- ร่างอักขระสามารถเลียนรูปลักษณ์เจ้าหน้าที่และซ่อนตัวจากการตรวจทั่วไป แต่ธรรมชาติและผู้สร้างยังไม่ทราบ
- หนังสือเก่า ภาพประตู ทารก และเชือกสิบแปดสายเป็นวัตถุชักนำที่ต้องตรวจสอบ มิใช่บันทึกยืนยันอดีต
- คำอ้างว่าอันเฉินมาจากประตูและชายปริศนาเคยช่วยเขายังไม่ยืนยัน ห้ามเขียนเป็นความจริง
- กำไลโลหิตอสูรอัคคีและหอกเป็นของภูติระดับสูงในแดนภูติ ห้ามเปิดเผยเจ้าของเดิมก่อนเวลา
- จุดเริ่มเล่นต่อล่าสุด: วันแรกที่สำนักมือปราบ กำลังสืบคดีร้านอาหารถูกขโมยของและมีกลิ่นอายภูติหลายตน
