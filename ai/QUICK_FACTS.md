# QUICK FACTS — สำหรับ AI ที่เปิดเล่นต่อ

## ตอนนี้คือช่วงไหน
หลังเหตุร่างอักขระในท้องพระโรง — จิ่งอันเลือกพักผ่อนและพาเซวียนเอ๋อร์ + จิ้งจอกสองตนออกไปเที่ยวตลาดกลางคืน

## ตัวละครหลัก
- พระเอก: หลี่จิ่งอัน (องค์ชายรอง) — เที่ยวเล่น รักสนุก แต่มีไหวพริบ เมตตาภูติ และกำลังถูกชักนำให้สงสัยชาติกำเนิด
- พี่ชาย: หลี่จิ่งเจิ้น (รัชทายาท) — สนิทกันมากและปกป้องจิ่งอันอย่างชัดเจน
- น้องสาว: หลี่จิ่งเหยา (องค์หญิง เดิมชื่อซัวเหยา) — สดใส ช่างสังเกต
- นางเอก: หลินเซวียนเอ๋อร์ (องค์หญิงหนานเจียง) — คนใกล้ชิดเรียก “เอ๋อร์”
- จิ้งจอกเก้าหาง: ว่างเหยียน + อู่อี — คู่สัญญาขั้นต้นของจิ่งอัน / ระดับม่วง / อายุราว 2,000 ปี
- ภูติแมวดำของนางเอก: เสี่ยวเถา — คู่สัญญาของเซวียนเอ๋อร์ / ระดับขาว / อายุราว 100 ปี
- ตระกูลแม่ทัพเมืองหลวง: มู่เหยียน + มู่เฉิง (25) + มู่หลัน (21)

## Feeling
ช่วงผ่อนคลายหลังเหตุการณ์หนัก ความสัมพันธ์ระหว่างจิ่งอันกับภูติและนางเอกใกล้ชิดขึ้นผ่านการเที่ยวเมือง

## กฎภูติที่ต้องจำ
- ภูติระดับขาวขึ้นไปมีสามร่าง: ร่างสัตว์เล็ก / ร่างกึ่งมนุษย์ / ร่างจำแลงเป็นมนุษย์
- เชือกสวรรค์ปรากฏตอนทำสัญญา และปรากฏอีกครั้งก่อนสลายเมื่อคู่สัญญาฝ่ายหนึ่งตาย
- พันธสัญญาขั้นสุดท้ายเกิดเมื่อภูติสมัครใจบอกนามจริงแก่เจ้าของหลังความสัมพันธ์ถึงขีดสุด
- จิ่งอัน + ว่างเหยียน + อู่อี → ร่างจิ้งจอกสวรรค์สีทอง + กระบี่จิ้งจอกสวรรค์
- นามจริงของว่างเหยียนและอู่อียังเป็นความลับ

## หน่วยงานภูติ
- กรมภูติหลวง: ทะเบียนผู้ใช้ภูติ รายงานเหตุ และประวัติสำคัญ
- หอจดหมายเหตุภูติ: ทะเบียนเก่า รายงานคดี และข้อมูลสำหรับการสืบสวน
- สำนักฝึกภูติ: ฝึกและรักษาภูติ ส่วนใหญ่รองรับระดับเขียว–เหลือง
- ภูติระดับขาวขึ้นไปดึงพลังเจ้าของมารักษาตัวเองได้ ทำให้เจ้าของอ่อนแรง

## เหตุการณ์ล่าสุด
- จิ่งอันจัดห้องในตำหนักให้ว่างเหยียนและอู่อี
- อู่อีชอบไก่ตุ๋นมาก
- จิ่งอันพาเซวียนเอ๋อร์ ว่างเหยียน อู่อี ลอบออกจากวังไปเที่ยวตลาดกลางคืน
- ซื้อปิ่นของฝาก: หยกขาวให้ว่างเหยียน / มณีให้อู่อี / ลายแมวให้เซวียนเอ๋อร์
- พูดคุยเรื่องหนานเจียง (ชาเขียว ปลาดิบ ข้าวหน้าปลาไหล มิโกะ)
- คนของแม่ทัพมู่ตามจิ่งอันมา 2 คน (ตามมาตั้งแต่จิ่งอันอายุ 14)
- เสี่ยวเถายังสื่อสารทางจิตกับจิ่งอันได้ชัดเจน

## ห้ามย้อนกลับ / ห้ามเฉลยเกินข้อมูล
- พิธีอัญเชิญเกิดขึ้นแล้ว
- จิ่งอันมีว่างเหยียนและอู่อีเป็นคู่สัญญาขั้นต้นแล้ว
- เซวียนเอ๋อร์มีเสี่ยวเถาเป็นคู่สัญญาแล้ว
- ห้ามให้จิ่งอันใช้พลังเต็มรูปแบบ พันธสัญญานามแท้ หรือรู้ชื่อนามจริง
- ห้ามยืนยันว่าจิ่งอันมาจากประตู หรือว่าชายปริศนาเคยช่วยเขา เพราะหลักฐานในหนังสือถูกสร้างเพื่อชักนำ
- ปมร่างอักขระ แผ่นโลหะ และประตูยังค้างอยู่ ห้ามเฉลยในฉากผ่อนคลายนี้
