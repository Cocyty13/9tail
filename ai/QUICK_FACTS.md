# QUICK FACTS — สำหรับ AI ที่เปิดเล่นต่อ

## ตอนนี้คือช่วงไหน
วันแรกที่สำนักมือปราบ — อันเฉินและเยว่หลินเป็นมือปราบฝึกหัด กำลังเริ่มสืบคดีร้านอาหารถูกขโมยของและมีกลิ่นอายภูติหลายตน

## ตัวละครหลัก (ชื่อย่อสองพยางค์)
- พระเอก: **หลี่ อันเฉิน** — เรียก **อันเฉิน**  
  ปราณอัคคีดั้งเดิม / คู่สัญญาว่างเหยียน+อู่อี / ซึมซับพลังภูติได้ / ครอบครองกำไลโลหิตอสูรอัคคี + หอกลึกลับ / มือปราบฝึกหัด
- พี่ชาย: หลี่ จิ่งเจิ้น — เรียก **จิ่งเจิ้น** (อดีตมือปราบ)
- น้องสาว: **หลี่ เหยาเฟย** — เรียก **เหยาเฟย**
- นางเอก: **หลิน เยว่หลิน** — เรียก **เยว่หลิน**  
  ปราณบุปผา / คู่สัญญาเสี่ยวเถา / วิชาขลุ่ยบุปผา (ท่าห้วงสะกด) / มือปราบฝึกหัด
- จิ้งจอกเก้าหาง: ว่างเหยียน + อู่อี — คู่สัญญาขั้นต้นของอันเฉิน / ระดับม่วง / อายุราว 2,000 ปี
- ภูติแมวดำ: เสี่ยวเถา — คู่สัญญาของเยว่หลิน / ระดับขาว / เคยเผยร่างกึ่งภูติแล้ว
- หัวหน้ากองสำนักมือปราบ: กู้เหวินโจว

## Feeling
เริ่มเข้าสู่ภาคปฏิบัติการจริงในฐานะมือปราบ มีทั้งการฝึกฝน พลังใหม่ และคดีภูติ

## ระบบสำคัญที่ต้องจำ
### ปราณ
- หนึ่งคนมีปราณกำเนิดได้เพียงหนึ่งชนิดตลอดชีวิต
- ปราณดั้งเดิม: พสุธา / วารี / วายุ / อัคคี
- อันเฉิน = อัคคีดั้งเดิม | เยว่หลิน = บุปผา (อนุพันธ์วารี)

### ซึมซับพลัง
- นายสามารถดึงพลังกลับจากภูติได้ (อันเฉินเริ่มใช้ได้แล้ว)

### กำไลโลหิตอสูรอัคคี
- เลือกอันเฉินเอง สวมแล้วถอดไม่ออก
- ปลดผนึกหอกที่มีเจตจำนง ว่างเหยียน+อู่อีรู้จักแต่ไม่ยอมบอกเจ้าของเดิม

## ห้ามย้อนกลับ / ห้ามเฉลยเกินข้อมูล
- พิธีอัญเชิญเกิดขึ้นแล้ว
- อันเฉินมีว่างเหยียนและอู่อีเป็นคู่สัญญาขั้นต้นแล้ว
- เยว่หลินมีเสี่ยวเถาเป็นคู่สัญญาแล้ว
- ห้ามให้อันเฉินใช้พลังเต็มรูปแบบ พันธสัญญานามแท้ หรือรู้ชื่อนามจริง
- ห้ามเปิดเผยเจ้าของเดิมของกำไลโลหิตอสูรอัคคี
- ห้ามยืนยันว่าอันเฉินมาจากประตู
- ปมร่างอักขระ แผ่นโลหะ และประตูยังค้างอยู่
