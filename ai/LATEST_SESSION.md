# LATEST SESSION — เที่ยวตลาดกลางคืนกับองค์หญิงหนานเจียง

## สรุปเหตุการณ์ก่อนหน้า
- หลังร่างอักขระสลายในท้องพระโรง จิ่งอันเลือกพักผ่อนและมอบการสืบสวนให้แม่ทัพมู่
- จัดห้องในตำหนักองค์ชายรองให้ว่างเหยียนและอู่อี
- เช้าวันรุ่งขึ้น อู่อีกินไก่ตุ๋นอย่างมีความสุข ว่างเหยียนกินอย่างสงบ
- จิ่งอันถามเรื่องชีวิตในภพภูติ ทั้งคู่เล่าถึงหุบเขา ผลไม้ป่า และการล่าสัตว์เล็ก

## การลอบออกจากวัง
- จิ่งอันชวนเซวียนเอ๋อร์ไปเที่ยวเมืองโดยไม่บอกใครล่วงหน้า
- ปีนต้นไม้ข้ามกำแพงวังด้านตะวันตก
- ว่างเหยียนและอู่อีใช้ร่างจำแลง
- เซวียนเอ๋อร์มาเจอขณะปีนต้นไม้ และขอร่วมด้วย
- จิ่งอันเรียกเซวียนเอ๋อร์สั้น ๆ ว่า “เอ๋อร์”
- มีคนของแม่ทัพมู่ตามจิ่งอันมา 2 คน (ตามมาตั้งแต่จิ่งอันอายุ 14 ปี) จิ่งอันรู้และไม่สนใจ

## ตลาดกลางคืน
- เดินชมตลาด ซื้อของกินหลายอย่าง (ลูกชิ้นปิ้ง พายเนื้อ แป้งทอด บัวลอยน้ำขิง ปลาแห้งให้เสี่ยวเถา)
- จิ่งอันซื้อปิ่นเป็นของฝาก:
  - ปิ่นพระจันทร์ประดับหยกขาว → ให้ว่างเหยียน
  - ปิ่นพระจันทร์ประดับมณีสีแดง → ให้อู่อี
  - ปิ่นลายแมว → ให้เซวียนเอ๋อร์
- พูดคุยเรื่องเมืองหนานเจียง:
  - อากาศอุ่น ฝนตกบ่อย ทะเลสวย มีเกาะเล็ก
  - อาหารเด่น: ชาเขียวใบอ่อน ปลาดิบ ข้าวหน้าปลาไหลย่างซอหวาน (ของโปรดเซวียนเอ๋อร์)
  - มีนักบวชหญิงเรียกว่า “มิโกะ” สวมชุดขาวแดง คอยดูแลศาลเจ้าใกล้ทะเล

## ปมและสถานะปัจจุบัน
- ยังไม่มีการสืบสวนเพิ่มเรื่องร่างอักขระ แผ่นโลหะ หรือประตูในรอบนี้
- ความสัมพันธ์ระหว่างจิ่งอัน–ว่างเหยียน–อู่อี–เซวียนเอ๋อร์ใกล้ชิดขึ้นเล็กน้อยผ่านการเที่ยวและของฝาก
- เสี่ยวเถายังสื่อสารทางจิตกับจิ่งอันได้ชัดเจน
- จุดเล่นต่อ: ยังอยู่ในตลาดกลางคืน หรือกลับวังหลังเที่ยว

## ฉากปัจจุบัน
- กลุ่มกำลังเดินชมตลาดกลางคืนใจกลางเมือง
- จิ่งอัน เซวียนเอ๋อร์ ว่างเหยียน อู่อี และเสี่ยวเถา
- มีเงาคนของแม่ทัพมู่ตามมา 2 คนในระยะห่าง
