# LATEST SESSION — เงาอักขระในท้องพระโรง

## ต่อจากลานพิธี
- ทหารหลวงรื้อเศษฐานหินอัคคี ขณะที่หมอหลวงและกรมภูติย้ายงูยักษ์ไปรักษา แก่นวิญญาณยังไม่ดับ
- เสี่ยวเถาได้กลิ่นของประตูใต้ฐานพิธี และสื่อสารกับจิ่งอันทางจิตได้ชัดเจน แต่เซวียนเอ๋อร์ยังไม่ได้ยิน
- มู่เหยียนนำแผ่นโลหะสีดำสลักจันทร์เสี้ยวมาให้ตรวจ พบว่าถูกฝังใต้ฐานอย่างน้อยหลายเดือน
- ผู้ฝังแผ่นโลหะต้องผ่านการตรวจของวัง เข้าถึงเขตพิธี และรู้โครงสร้างใต้ฐานหิน
- ว่างเหยียนยอมรับว่าเคยเห็นสัญลักษณ์จันทร์เสี้ยวสีดำ
- รอยแยกใต้ฐานเปล่งแสงแดงหม่น และมีเสียงเคาะจากใต้พื้นสามครั้ง

## ชายปริศนาในท้องพระโรง
- ชายผู้สวมชุดเจ้าหน้าที่หอสมุดปรากฏพร้อมหนังสือเก่าและเปลวไฟสีดำ
- เขารู้จักจิ่งเจิ้นมาก่อนทั้งที่จิ่งเจิ้นไม่เคยเห็นเขา
- ป้ายเจ้าหน้าที่บนอกของเขากลายเป็นสีดำและแตกสลาย
- ข้อมือไม่มีตราจันทร์เสี้ยว แต่มีแผลวงกลมคล้ายตราหรือสิ่งใดเคยถูกควักออก
- เขาอ้างว่าเคยเป็นคนของจันทราดับ ทรยศองค์กรเมื่อ 17 ปีก่อน ซึ่งตรงกับปีประสูติของจิ่งอัน
- หนังสือเปิดไปยังภาพประตูหินใต้ท้องฟ้าสีเลือด มีทารกข้อมือพันด้วยเชือกสิบแปดสาย
- ชายปริศนาคุกเข่าต่อหน้าจิ่งอันและอ้างว่าเป็นผู้พาจิ่งอันออกมาจากประตู

## การตรวจสอบตัวตน
- ว่างเหยียนและอู่อีพบว่ากลิ่นของชายผู้นั้นไม่ใช่มนุษย์ ภูติ หรือปีศาจ
- อู่อีฟันใบหน้าเขาแต่ไม่มีเลือดหรือเนื้อ ใต้ผิวมีอักขระสีดำจำนวนมาก
- ร่างนั้นไม่มีแก่นวิญญาณ เส้นชีพจร หรือกลิ่นของผู้สร้าง
- ว่างเหยียนยืนยันว่าไม่ใช่หุ่นอาคม และอู่อียืนยันว่าไม่ใช่ร่างจำแลง
- ก่อนจะเปิดเผยว่าพวกเขาเรียกร่างชนิดนี้ว่าอะไร อักขระหยุดทำงานและร่างเริ่มแตกร้าว
- ชายปริศนากล่าวว่าคำอ้างเรื่องประตูอาจจริง หรืออาจเป็นคำลวงที่จันทราดับต้องการให้เชื่อ
- ร่างของเขาสลายเป็นอักขระและถูกไฟดำเผาหาย ทิ้งหนังสือไว้
- จิ่งอันได้ยินเสียงกระซิบเพียงผู้เดียวว่า “อย่าเชื่อแม้แต่ความทรงจำของตนเอง”
- ว่างเหยียนตรวจพบว่าภาพทารกกับเชือกสิบแปดสายในหนังสือเพิ่งถูกวาดขึ้น
- ข้อสรุปปัจจุบัน: มีผู้สร้างเรื่องราวเพื่อทำให้จิ่งอันเริ่มสงสัยชาติกำเนิดของตนเอง คำกล่าวของชายปริศนายังไม่ใช่ความจริงที่ยืนยันแล้ว

## ปมค้าง
- ใครสร้างและควบคุมร่างอักขระ และร่างชนิดนี้เรียกว่าอะไร
- ตัวจริงของเจ้าหน้าที่หอสมุดอยู่ที่ใด
- ชายปริศนาเคยเป็นคนของจันทราดับจริงหรือไม่
- เหตุใดเขาจึงเลือกปีประสูติของจิ่งอันและภาพเชือกสิบแปดสายมาชักนำ
- คำเตือนเรื่องความทรงจำเป็นเบาะแสหรือกับดัก
- แผ่นโลหะใต้ฐานถูกฝังโดยใคร และเกี่ยวข้องกับคนในวังคนใด
- เสียงเคาะสามครั้งใต้ฐานพิธีมาจากอะไร
- ประตูใต้หินอัคคีคืออะไร และเหตุใดว่างเหยียนกับอู่อีจึงรู้จัก
- เหตุใดจิ่งอันจึงได้ยินเสียงทางจิตของเสี่ยวเถาก่อนเซวียนเอ๋อร์

## ฉากปัจจุบัน
- อยู่ในท้องพระโรงหลังร่างชายปริศนาสลาย
- หนังสือเก่ายังคงอยู่บนพื้น ว่างเหยียนยืนยันว่าภาพชาติกำเนิดเพิ่งถูกสร้าง
- จิ่งอัน ฮ่องเต้ จิ่งเจิ้น ว่างเหยียน อู่อี ไป๋เยว่ เสวียนหลิน และเจ้ากรมภูติอยู่ในเหตุการณ์
- ต้องเริ่มต่อจากการตรวจหนังสือ อักขระ และตัวจริงของเจ้าหน้าที่หอสมุด
