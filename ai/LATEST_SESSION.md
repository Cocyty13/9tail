# LATEST SESSION — เที่ยวตลาดกลางคืนกับองค์หญิงหนานเจียง

## สรุปเหตุการณ์ก่อนหน้า
- หลังร่างอักขระสลายในท้องพระโรง อันเฉินเลือกพักผ่อนและมอบการสืบสวนให้แม่ทัพมู่
- จัดห้องในตำหนักองค์ชายรองให้ว่างเหยียนและอู่อี
- เช้าวันรุ่งขึ้น อู่อีกินไก่ตุ๋นอย่างมีความสุข ว่างเหยียนกินอย่างสงบ
- อันเฉินถามเรื่องชีวิตในภพภูติ ทั้งคู่เล่าถึงหุบเขา ผลไม้ป่า และการล่าสัตว์เล็ก

## การลอบออกจากวัง
- อันเฉินชวนเยว่หลินไปเที่ยวเมืองโดยไม่บอกใครล่วงหน้า
- ปีนต้นไม้ข้ามกำแพงวังด้านตะวันตก
- ว่างเหยียนและอู่อีใช้ร่างจำแลง
- เยว่หลินมาเจอขณะปีนต้นไม้ และขอร่วมด้วย
- อันเฉินเรียกเยว่หลินสั้น ๆ ว่า “เยว่หลิน”
- มีคนของแม่ทัพมู่ตามอันเฉินมา 2 คน (ตามมาตั้งแต่อันเฉินอายุ 14 ปี) อันเฉินรู้และไม่สนใจ

## ตลาดกลางคืน
- เดินชมตลาด ซื้อของกินหลายอย่าง (ลูกชิ้นปิ้ง พายเนื้อ แป้งทอด บัวลอยน้ำขิง ปลาแห้งให้เสี่ยวเถา)
- อันเฉินซื้อปิ่นเป็นของฝาก:
  - ปิ่นพระจันทร์ประดับหยกขาว → ให้ว่างเหยียน
  - ปิ่นพระจันทร์ประดับมณีสีแดง → ให้อู่อี
  - ปิ่นลายแมว → ให้เยว่หลิน
- พูดคุยเรื่องเมืองหนานเจียง:
  - อากาศอุ่น ฝนตกบ่อย ทะเลสวย มีเกาะเล็ก
  - อาหารเด่น: ชาเขียวใบอ่อน ปลาดิบ ข้าวหน้าปลาไหลย่างซอหวาน (ของโปรดเยว่หลิน)
  - มีนักบวชหญิงเรียกว่า “มิโกะ” สวมชุดขาวแดง คอยดูแลศาลเจ้าใกล้ทะเล

## ปมและสถานะปัจจุบัน
- ยังไม่มีการสืบสวนเพิ่มเรื่องร่างอักขระ แผ่นโลหะ หรือประตูในรอบนี้
- ความสัมพันธ์ระหว่างอันเฉิน–ว่างเหยียน–อู่อี–เยว่หลินใกล้ชิดขึ้นเล็กน้อยผ่านการเที่ยวและของฝาก
- เสี่ยวเถายังสื่อสารทางจิตกับอันเฉินได้ชัดเจน
- จุดเล่นต่อ: ยังอยู่ในตลาดกลางคืน หรือกลับวังหลังเที่ยว

## ฉากปัจจุบัน
- กลุ่มกำลังเดินชมตลาดกลางคืนใจกลางเมือง
- อันเฉิน เยว่หลิน ว่างเหยียน อู่อี และเสี่ยวเถา
- มีเงาคนของแม่ทัพมู่ตามมา 2 คนในระยะห่าง
