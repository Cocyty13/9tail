# LATEST SESSION — พิธีอัญเชิญโลหิต

## จุดเริ่ม
- หลี่จิ่งอันกังวลว่าตนไม่มีพลังสวรรค์ เพราะไม่เคยแสดงปฏิกิริยาใดมาก่อน
- หลี่จิ่งเจิ้นยืนยันว่าต่อให้ไม่ได้ภูติ จิ่งอันก็ยังเป็นน้องชายและองค์ชายรองเช่นเดิม
- หลินเซวียนเอ๋อร์มาถึงในฐานะตัวแทนหนานเจียง ทั้งสองจำกันได้จากเหตุชนกันในงานโคมไฟ
- ปีนี้มีผู้เข้าพิธี 44 คน มากกว่าปกติ แต่ผู้ได้รับการตอบรับกลับน้อยผิดปกติ

## ความผิดปกติของพิธี
- ภูติที่ปรากฏส่วนใหญ่เป็นภูติวัยเยาว์ระดับเขียว
- แทบไม่มีภูติเต็มวัยหรือสัตว์ศักดิ์สิทธิ์ขนาดใหญ่ตอบรับ
- เซวียนเอ๋อร์เรียกเสี่ยวเถา ภูติแมวดำระดับขาว และทำสัญญาสำเร็จ
- เมื่อถึงลำดับของจิ่งอัน หินอัคคีไม่ตอบรับแม้แตะสองครั้ง

## การลอบสังหาร
- มือสังหารปรากฏจากเงารอบแท่นและมุ่งเป้าจิ่งอัน
- ว่างเหยียนและอู่อีปรากฏในร่างกึ่งมนุษย์ และยอมทำพันธสัญญาขั้นต้นกับจิ่งอัน
- ระหว่างประสานสัญญา จิ่งอันเห็นนิมิตประตูหิน ท้องฟ้าสีเลือด และสัญลักษณ์จันทร์เสี้ยวสีดำ
- มือสังหารใช้เข็มกระตุ้นตราเคลื่อนย้ายใต้ฐานหินอัคคี ส่งงูยักษ์เข้ามา
- งูถูกตราควบคุมบังคับให้โจมตีและเตรียมระเบิดแก่นวิญญาณ

## การช่วยงูยักษ์
- มู่เหยียนระบุว่าต้องจับผู้ควบคุม ทำลายแกนตราเคลื่อนย้ายสี่ทิศ และตัดตราควบคุมพร้อมกัน
- จิ่งเจิ้น มู่เหยียน จิ่งอัน และเสี่ยวเถาทำลายแกนตราทั้งสี่
- ว่างเหยียนระงับจิตของงู อู่อีตัดตราควบคุม และมู่เฉิงจับผู้ควบคุม
- งูรอดชีวิต แต่แก่นวิญญาณบาดเจ็บหนัก
- ผู้ควบคุมกัดยาพิษตาย มีตราจันทร์เสี้ยวสีดำบนข้อมือ
- ผู้สั่งการอีกคนปรากฏบนหลังคาชั่วครู่ก่อนหลบหนี

## ข้อมูลตัวละครที่เปิดเผย
- ว่างเหยียนและอู่อีมีอายุราว 2,000 ปี แต่ไม่ยอมบอกว่าอยู่ที่ใดมาตลอดช่วงเวลานั้น
- เสี่ยวเถามีอายุราว 100 ปี และยังควบคุมร่างกึ่งมนุษย์/ร่างจำแลงไม่ได้มั่นคง
- กิเลนดำของจิ่งเจิ้นชื่อเสวียนหลิน
- เสือขาวของฮ่องเต้ชื่อไป๋เยว่และเป็นตัวเมีย
- ชื่อเหล่านี้เป็นชื่อเรียกทั่วไป ไม่ใช่นามจริงของแก่นวิญญาณ

## ปมค้าง
- เหตุใดภูติเต็มวัยจึงหลีกเลี่ยงพิธี
- ผู้ใดฝังตราเคลื่อนย้ายใต้หินอัคคี
- ผู้สั่งการที่หลบหนีคือใคร
- สัญลักษณ์จันทร์เสี้ยวสีดำเกี่ยวข้องกับสิ่งใด
- ประตูใต้หินอัคคีคืออะไร และเหตุใดว่างเหยียนกับอู่อีจึงรู้จัก
- เหตุใดจิ่งอันจึงได้ยินเสียงทางจิตของเสี่ยวเถาก่อนเซวียนเอ๋อร์

## ฉากปัจจุบัน
- ทหารกำลังเคลียร์ลานพิธี เก็บหลักฐาน รักษาผู้บาดเจ็บ และคุมตัวมือสังหาร
- เสี่ยวเถาบอกจิ่งอันว่าได้กลิ่น “ประตูที่ไม่ควรเปิดจากฝั่งนี้” ใต้หินอัคคี
