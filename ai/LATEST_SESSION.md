# LATEST SESSION — ถูกลอบโจมตี → ฝึกปราณ → เข้าสำนักมือปราบ

## สรุปเหตุการณ์ก่อนหน้า
- อันเฉินพาเยว่หลิน ว่างเหยียน อู่อี ออกเที่ยวตลาดกลางคืน
- ซื้อปิ่นของฝากและพูดคุยเรื่องหนานเจียง
- มีองครักษ์ลับของแม่ทัพมู่ตามมา

## เหตุการณ์ที่ 1 : ถูกลอบโจมตีกลางคืน
- สถานที่: ถนนเปลี่ยวระหว่างเดินกลับจากตลาด
- มือสังหารชุดดำประมาณ 20 คนดักโจมตี
- มีผู้ใช้ภูติ 2–3 คนร่วมปฏิบัติการ (ภูติหมาป่า, ภูติอสรพิษ, ภูติเหยี่ยว)
- องครักษ์ของแม่ทัพมู่เข้าปกป้องแต่เสียเปรียบจากจำนวน
- ผู้ร่วมเหตุการณ์: อันเฉิน, เยว่หลิน, ว่างเหยียน, อู่อี, เสี่ยวเถา, องครักษ์ลับของแม่ทัพมู่

## เหตุการณ์ที่ 2 : เสี่ยวเถาเผยร่างกึ่งภูติ
- รูปลักษณ์: หญิงสาวผมสั้นสีดำ มีหูแมวดำ กระโปรงสั้น กางเกงด้านในสำหรับต่อสู้ ใช้คุไนคู่
- ความสามารถ: ความเร็วสูง ต่อสู้อากาศ รับมือภูติเหยี่ยวได้

## เหตุการณ์ที่ 3 : การซึมซับพลังภูติ
- ว่างเหยียนอธิบายระบบใหม่: ภูติดึงพลังจากนายได้ แต่นายก็สามารถดึงพลังกลับจากภูติได้เช่นกัน
- ยิ่งภูติระดับสูง การซึมซับยิ่งรวดเร็ว
- อันเฉินเริ่มใช้ได้เองโดยสัญชาตญาณ
- ผลที่เกิดขึ้น: ความเร็วเพิ่ม ประสาทสัมผัสดีขึ้น ปัดอาวุธได้เอง

## เหตุการณ์ที่ 4 : การถอนกำลังของศัตรู
- ศัตรูจุดพลุสัญญาณแล้วถอนกำลังทันที
- สันนิษฐานว่าจุดประสงค์คือทดลองพลังของอันเฉิน ไม่ใช่ลอบสังหารจริง

## เหตุการณ์ที่ 5 : การปรากฏตัวของกิเลนดำ
- ภูติกิเลนดำของรัชทายาท (เสวียนหลิน) จับผู้ใช้ภูติฝ่ายศัตรูได้หนึ่งคน
- ส่งไปสอบสวน

## เหตุการณ์ที่ 6–7 : ตรวจพบปราณกำเนิด + ระบบปราณ (Canon ใหม่)
- เริ่มฝึกกับแม่ทัพมู่ และมีการอธิบายระบบปราณใหม่ทั้งหมด

### ระบบปราณ (Canon)
- ผู้ใช้ภูติมีปราณกำเนิดได้เพียงหนึ่งชนิดตลอดชีวิต ไม่มีข้อยกเว้น
- ปราณดั้งเดิมมีเพียง 4 ชนิด: พสุธา / วารี / วายุ / อัคคี
- ปราณอนุพันธ์:
  - พสุธา → หิน, ทราย, โลหะ, ไม้, พืช
  - วารี → น้ำแข็ง, หมอก, บุปผา, พิษ
  - วายุ → เสียง, ความเร็ว, ความดันอากาศ
  - อัคคี → ลาวา, ควัน, ระเบิด, ความร้อน
- กฎ: หนึ่งคนมีหนึ่งปราณกำเนิด / ปราณย่อยมาจากต้นกำเนิดเพียงสายเดียว / ปราณดั้งเดิมเหนือกว่าปราณย่อย / แขนงใหม่ต้องระบุสายต้นกำเนิด

### ผลตรวจปราณ
- อันเฉิน → ปราณอัคคีดั้งเดิม (Origin Fire) เป็นหนึ่งในสี่ปราณสูงสุด
- เยว่หลิน → ตรวจครั้งแรกตอบสนองสายวารี ภายหลังพบว่าเป็นปราณบุปผา (อนุพันธ์สายวารี)

## เหตุการณ์ที่ 8 : ว่างเหยียนพัฒนากระบวนท่าขลุ่ยบุปผา
- สร้างจากวิชาขลุ่ยภูติดั้งเดิม + ปราณบุปผา
- กระบวนท่าที่ 1 “ห้วงสะกด”:
  - ใช้เสียง + กลิ่น + เกสร + ปราณบุปผา
  - ทำให้ศัตรูเสียสมาธิ (ไม่ใช่การสะกดจิต)
  - เหมาะสำหรับจับกุม ควบคุมฝูงชน สนับสนุน
  - ผู้ใช้: เยว่หลิน / ผู้สอน: ว่างเหยียน

## เหตุการณ์ที่ 9 : จักรพรรดิส่งกำไลโลหิตอสูรอัคคี
- ที่มา: นักพรตอู่สือฝากไว้ตั้งแต่จักรพรรดิยังหนุ่ม กล่าวว่าวันหนึ่งกำไลจะเลือกเจ้าของเอง
- กำไลตอบสนองต่ออันเฉินทันที สวมข้อมือเอง และถอดไม่ออก
- ว่างเหยียนกับอู่อีรู้จักกำไลและตกใจมาก เรียกชื่อว่า “กำไลโลหิตอสูรอัคคี”
- เดิมเป็นของภูติระดับสูงในแดนภูติ แต่ทั้งคู่หยุดไม่ยอมบอกชื่อเจ้าของเดิม

## เหตุการณ์ที่ 10–11 : กำไลปลดผนึกอาวุธชิ้นแรก
- อาวุธ: หอก ด้ามสีแดงสด ใบหอกสีดำ มีพู่แดง
- พู่แดงคือพันธะสะกด ทำหน้าที่กดเจตจำนงของอาวุธ ป้องกันอาวุธย้อนทำร้ายเจ้าของ
- อาวุธมีเจตจำนงของตนเอง ลอยเองได้ ตอบสนองต่ออันเฉิน และส่งความทรงจำบางส่วนเข้าสู่จิต
- อันเฉินได้รับความรู้เบื้องต้นของหอกจากอาวุธโดยตรง แต่ยังควบคุมไม่ได้ หัวทิ่มจากน้ำหนักพลังวิญญาณของหอก

## เหตุการณ์ที่ 12 : แต่งตั้งเข้าสำนักมือปราบ
- รัชทายาทเปิดเผยคำสั่งใหม่
- อันเฉินและเยว่หลินได้รับแต่งตั้งเข้าประจำสำนักมือปราบ กรมภูติหลวง
- เหตุผล: ฝึกใช้งานจริง ออกนอกวังได้ถูกต้อง ไม่ต้องลอบหนี

## เหตุการณ์ที่ 13 : วันแรกที่สำนักมือปราบ
- หัวหน้ากอง: กู้เหวินโจว (อดีตผู้ใต้บังคับบัญชาของรัชทายาท)
- กฎ: ไม่มีองค์ชาย ไม่มีองค์หญิง มีเพียงมือปราบฝึกหัด
- คดีแรก: ร้านอาหารถูกขโมยของ (ข้าวสาร เนื้อ ไก่ ซาลาเปา)
- ตรวจพบกลิ่นอายภูติ
- มือปราบที่เคยสืบสลบ และพบกลิ่นภูติหลายตนในพื้นที่เดียว

## สถานะตัวละครปัจจุบัน
- อันเฉิน: ปราณอัคคีดั้งเดิม / คู่สัญญาว่างเหยียน+อู่อี / ซึมซับพลังภูติได้ / ครอบครองกำไลโลหิตอสูรอัคคี / ปลดผนึกหอกลึกลับ / เริ่มฝึกหอกกับแม่ทัพมู่ / มือปราบฝึกหัด
- เยว่หลิน: ปราณบุปผา / คู่สัญญาเสี่ยวเถา / วิชาขลุ่ยบุปผา (ท่าห้วงสะกด) / มือปราบฝึกหัด
- ว่างเหยียน: ผู้สอนปราณ / พัฒนากระบวนท่าขลุ่ยบุปผา / รู้ความลับกำไลแต่ปิดบังชื่อเจ้าของเดิม
- อู่อี: รู้จักกำไลและเจ้าของเดิม แต่ถูกว่างเหยียนห้ามเปิดเผย
- จิ่งเจิ้น: อดีตมือปราบ / ควบคุมการฝึก / ส่งทั้งคู่เข้าสำนัก
- แม่ทัพมู่: อาจารย์สอนปราณและพื้นฐานหอก

## ฉากปัจจุบัน
- วันแรกที่สำนักมือปราบ
- กำลังเริ่มสืบคดีร้านอาหารถูกขโมยของและมีกลิ่นอายภูติหลายตน
