# RELATIONSHIP MAP

## ราชวงศ์ต้าลี่
- ฮ่องเต้ หลี่เทียนเชิง ← พ่อ
- ฮองเฮา เซี่ยหมิงเยว่ ← แม่ของจิ่งเจิ้น + จิ่งอัน + จิ่งเหยา
- หลี่จิ่งเจิ้น (รัชทายาท) ← พี่ชายที่จิ่งอันสนิทที่สุด
- หลี่จิ่งเหยา (เดิมชื่อซัวเหยา) ← น้องสาว
- หลี่เฉิน + หลี่หยาง ← ลุง (หน้าดี เบื้องหลังมีแผน)

## ตระกูลแม่ทัพมู่แห่งต้าลี่จิง
- มู่เหยียน ← แม่ทัพผู้ภักดีต่อราชบัลลังก์ และเป็นบิดาของมู่เฉิงกับมู่หลัน
- มู่เฉิง ← สหายฝึกอาวุธของจิ่งเจิ้น / คอยจับตาความปลอดภัยของจิ่งอัน
- มู่หลัน ← เพื่อนวัยเด็กคู่กัดของจิ่งอัน / คนสนิทของจิ่งเหยา

## จิ้งจอก
- ว่างเหยียน + อู่อี ← คู่สัญญาขั้นต้นของหลี่จิ่งอัน / จิ้งจอกเก้าหางระดับม่วง / อายุราว 2,000 ปี
- ว่างเหยียน ← พี่สาวสุขุมสง่า / คอยควบคุมเรื่องวุ่นวายของอู่อี
- อู่อี ← น้องสาวซุกซนดุร้าย / ปกป้องว่างเหยียนและจิ่งอันแบบตรงไปตรงมา

## หนานเจียง
- หลิน หยวนชิง ← พ่อนางเอก
- หลิน เซวียนเอ๋อร์ ← นางเอก
- เสี่ยวเถา ← คู่สัญญาภูติแมวดำระดับขาวของนางเอก / อายุราว 100 ปี / คู่หูจอมวางแผน
- หยาง เจิ้นเฟิง ← แม่ทัพ

## ความเชื่อมโยงใหม่จากพิธี
- จิ่งอัน ↔ เสี่ยวเถา: ได้ยินเสียงสื่อสารทางจิตอย่างผิดปกติ แม้ไม่ใช่คู่สัญญา
- เซวียนเอ๋อร์ ↔ เสี่ยวเถา: เพิ่งทำสัญญา ความรู้สึกส่งถึงกันได้ แต่ยังไม่ได้ยินเป็นถ้อยคำ
- เสวียนหลิน ↔ ว่างเหยียน/อู่อี: ระวังตัวต่อกัน โดยอู่อีชอบยั่วและเรียกกิเลนว่า “เจ้าหมาน้อย”
- ว่างเหยียน/อู่อี ↔ ประตูใต้หินอัคคี: รู้จักหรือมีอดีตเกี่ยวข้อง แต่ยังไม่ยอมเปิดเผย

## การเมือง
- ฝ่ายรัชทายาท: หลี่จิ่งเจิ้น + จ้าวเหวินเจ๋อ + อู่เหวินเฉิง
- ตระกูลมู่: ภักดีต่อราชบัลลังก์ ไม่สังกัดฝ่ายองค์ชายคนใดโดยตรง
- ฝ่ายตรงข้ามฮองเฮา: ซุนหมิง + บางส่วนของตระกูลเก่า
