# RELATIONSHIP MAP

## ราชวงศ์ต้าลี่
- ฮ่องเต้ หลี่เทียนเชิง ← พ่อ
- ฮองเฮา เซี่ยหมิงเยว่ ← แม่ของเซวียน + ซัวเหยา
- หลี่เจิ้น (รัชทายาท) ← พี่ชายที่สนิทที่สุด
- หลี่ซัวเหยา ← น้องสาว
- หลี่เฉิน + หลี่หยาง ← ลุง (หน้าดี เบื้องหลังมีแผน)

## จิ้งจอก
- ว่างเหยียน + อู่อี ← ภูติของหลี่เซวียน (จะปรากฏวันพิธี)

## หนานเจียง
- หลิน หยวนชิง ← พ่อนางเอก
- หลิน เซวียนเอ๋อร์ ← นางเอก
- เสี่ยวเถา ← ภูติแมวสาวของนางเอก
- หยาง เจิ้นเฟิง ← แม่ทัพ

## การเมือง
- ฝ่ายรัชทายาท: หลี่เจิ้น + จ้าวเหวินเจ๋อ + อู่เหวินเฉิง
- ฝ่ายตรงข้ามฮองเฮา: ซุนหมิง + บางส่วนของตระกูลเก่า
