# 9tail

ฐานข้อมูล Roleplay สำหรับเรื่อง **จิ้งจอกเก้าหาง**

โลกแฟนตาซีจีนย้อนยุค ราชวงศ์ต้าลี่ + ระบบอัญเชิญภูติ

---

## โครงสร้างหลัก

ใช้ระบบเดียวกับ `zhao-db` เพื่อความต่อเนื่องในการเล่นยาว

- `ai/` → ข้อมูลที่ AI ต้องอ่านก่อนเล่นทุกครั้ง
- `ai/STYLE_GUIDE.md` → **คู่มือการเขียนหลัก (สำคัญสูงสุด)** จังหวะ น้ำเสียง บุคลิก และวิธีตอบ
- `WRITING_RULES.md` → กฎการใช้ภาษาและฐานันดร
- ไฟล์อื่นจะถูกเพิ่มตามการพัฒนาเรื่อง

**Branch ที่ใช้:** `main` (ปัจจุบัน)

---

## สำหรับ AI ที่เข้ามาเล่นใหม่

1. อ่าน `ai/STYLE_GUIDE.md` ก่อนเป็นอันดับแรกเสมอ
2. จากนั้นอ่าน `ai/QUICK_FACTS.md` → `CORE_SNAPSHOT.md` → `ACTIVE_PLOT.md` → `LATEST_SESSION.md`
3. เริ่มเล่นต่อจากสถานะปัจจุบัน
